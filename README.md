# StorySpill

Interactive bookshelf library (AevyTV-style UI) with full user + admin system.

## Setup
1. Put folder in htdocs/storyspill-reads
2. Import schema.sql then seed.sql in phpMyAdmin
3. Open http://localhost/storyspill-reads/
